# Pawtrait website changes

For every user-requested website change, create a fresh demo/<descriptive-change>-<date> branch before editing. Keep the original snapshot branch intact. Use reusable homepage parts and shared navigation configuration. Verify PHP syntax and the relevant desktop/mobile interactions. Push each completed demo to GitHub and open a draft PR. Never merge into main or deploy publicly unless the user requests it. Do not commit database exports, wp-config.php, private uploads or credentials.
